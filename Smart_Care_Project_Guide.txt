1. PROJECT OVERVIEW
------------------------------------------------------------------------
Smart Care AI is an intelligent, AI-powered hospital management system
that automates and enhances the entire patient experience — from the
moment they enter the hospital to post-discharge home care.

It consists of 4 main components:
  1. Backend (FastAPI + YOLOv8 + GPT-4o)   → The AI brain
  2. Hospital Kiosk (Next.js)               → Patient registration
  3. Doctor Dashboard (Next.js)             → Consultation & prescription
  4. Patient Mobile App (React Native/Expo) → AI Personal Nurse at home


2. HOW THE APP WORKS (COMPLETE END-TO-END FLOW)
------------------------------------------------------------------------

STEP 1: PATIENT ARRIVES AT HOSPITAL (SMART KIOSK)
--------------------------------------------------
- Patient stands in front of the Smart Care Kiosk.
- YOLOv8 (Computer Vision) detects the person in real-time via webcam.
- Face Recognition checks if this is a NEW patient or a returning one.
- The AI Receptionist (GPT-4o) greets the patient warmly in Telugu or
  English and conducts a full conversational triage:
    • Asks for name
    • Asks about symptoms
    • Asks natural human-like follow-up questions (e.g., "ఎప్పటినుంచి
      జ్వరం ఉంది?" / "How long have you had this fever?")
- Based on symptoms, AI determines Emergency Priority Level:
    • EMG (Emergency) → Chest pain, breathing difficulty, stroke
    • HPR (High Priority) → Severe fever, severe pain, swelling
    • NRM (Normal) → Mild fever, cold, routine issues
- Generates a unique Token (e.g., NRM-342) and adds patient to queue.

STEP 2: DOCTOR CONSULTATION (DOCTOR DASHBOARD)
-----------------------------------------------
- Doctor opens their dashboard and sees the real-time patient queue,
  sorted by priority (Emergency first).
- They select a patient and see the AI's clinical triage summary.
- Doctor uses Voice Dictation (Web Speech API) to speak prescriptions
  OR types them manually — whatever is faster.
- Clicks "Send to Patient App":
    → GPT-4o structures the raw notes into a clean prescription summary:
       Medications | Diet | Activity | Follow-up | Emergency Signs
    → Saved to patient's token for the mobile app.

STEP 3: PATIENT GOES HOME (AI PERSONAL NURSE - MOBILE APP)
-----------------------------------------------------------
- Patient downloads the Smart Care mobile app.
- Logs in using their Name + Token Number from hospital.
- Instantly sees their Prescription in organized, easy-to-read cards.
- AI Personal Nurse: Patient can chat with an AI Nurse (ChatGPT style).
  The AI knows their exact prescription and answers questions like:
    "ఈ మందు ఎప్పుడు వేసుకోవాలి?" / "When should I take this medicine?"
    "నేను ఏమి తినాలి?" / "What should I eat?"
  (AI does NOT prescribe new medications — only explains existing ones)

STEP 4: HOSPITAL HYGIENE MONITORING (NURSE/ADMIN DASHBOARD)
-------------------------------------------------------------
  *** THIS IS THE 4th MAJOR FEATURE — DO NOT MISS IN DEMO ***
- Nurse or Ward Coordinator opens the Hygiene Monitoring page.
- They capture or upload a photo of their hospital ward.
- GPT-4o Vision (AI) analyzes the image and gives:
    • Hygiene Score (0-100)
    • Status: Good ✅ / Warning ⚠️ / Critical 🚨
    • List of hygiene issues found (e.g., unclean floor, waste bins full)
    • Positive observations (e.g., clean beds, organized equipment)
    • WhatsApp-style message to send to the coordinator
    • Escalate flag (true if score < 50)
- AGENTIC ESCALATION SYSTEM:
    → If hygiene is WARNING/CRITICAL and not fixed within 60 minutes,
      the AI automatically escalates the issue to the HOD (Head of Dept)
    → Ward can be marked "Resolved" to stop the escalation timer
    → All escalation statuses can be tracked via /escalation/status API

5. HOW TO RUN THE SERVERS
------------------------------------------------------------------------
Run the complete project in 3 CMD/Terminal windows simultaneously:

SERVER 1: THE BACKEND (FastAPI)
  d:
  cd d:\google_hackthon\smart_care_ai\backend
  python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
  → Runs on: http://localhost:8000

SERVER 2: THE HOSPITAL KIOSK & DASHBOARD (Next.js)
  d:
  cd d:\google_hackthon\smart_care_ai\frontend
  npm run dev
  → Runs on: http://localhost:3000

SERVER 3: THE PATIENT MOBILE APP (Expo)
  d:
  cd d:\google_hackthon\smart_care_patient_app
  npx expo start --clear
  → Scan QR code with Expo Go app on phone
